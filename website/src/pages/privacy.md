# Legal & privacy

## Privacy notice for this website

*Dated 28 September 2026.*

- This site sets no cookies, runs no analytics, and loads nothing from third parties. Every page is static HTML with inline styles; the Content-Security-Policy on each page forbids scripts and external requests.
- It is hosted on GitHub Pages, whose servers log requests under [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- The sessionpipe software sends data only to the sinks a person configures. The project operates no server that receives anyone's data.
- Questions: privacy@sessionpipe.org (until that address is live: a GitHub Discussion).
