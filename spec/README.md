# The sessionpipe protocol

This directory is the contract. It is licensed under [CC BY 4.0](LICENSE) and
rendered at [sessionpipe.org/protocol](https://sessionpipe.org/protocol/).

| File | Covers |
|------|--------|
| PROTOCOL.md | envelope, event vocabulary, session block, tiers |
| HTTP.md | the HTTP binding: headers, batches, errors, retry, discovery |
| PRIVACY.md | the four tiers in detail, the rulesets, guidance for receivers |
| CONTROL.md | the channel back: permission answers, prompts, cancel |
| ADAPTERS.md | per-harness mapping tables |
| VERSIONING.md | the protocol integer, capabilities, deprecation, status |

Written in M1. The words MUST, SHOULD and MAY are used as in RFC 2119.
